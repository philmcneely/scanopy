This release is focused on the topology view: device cards now show what's actually running on each machine — containers, services, and their run states — alongside richer tooltips and clearer icons. Discovery also got smarter about containers, UniFi networks, and SNMP troubleshooting.

## New Features

- List a guest's containers directly on its topology card, with run state shown as an outlined marker so you can spot stopped workloads at a glance (also available in the Application view).
- Record UniFi networks as VLANs and subnets, and show a subnet's VLANs in its tooltip and inspector so controller-managed segments appear in your topology.
- Try credentials against containers behind bridge networks and probe their ports from the inside, revealing services that were previously invisible.
- Add per-host SNMP check commands to device warnings, giving you a ready-to-run command for each affected device instead of generic guidance.
- Detect Spring Boot, Celery, and Sidekiq workers as applications during discovery.
- Rescan addresses your daemon can reach by route, so networks beyond its directly attached subnets get picked up.

## Improvements

- Give every device type a distinct glyph and stack service badges on the card corner, making crowded topologies easier to read.
- Restructure tooltips across topology cards, OS, tags, and scan outcomes, and keep every popover inside the viewport.
- Lay out linked cards in dependency order and draw every hop of a dependency through tag groups, so application flows read top to bottom.
- Draw Layer 2 switch ports as rows for a consistent, compact port view.
- Speed up Proxmox and UniFi discovery by submitting guests, hosts, and subnets concurrently.
- Serve OIDC provider logos from Scanopy itself, so sign-in pages no longer reach out to third-party servers.
- Support images in release notes, so in-app announcements can show what's new.

## Bug Fixes

- Fix Layer 2 topologies that could fail to render by routing switch edges orthogonally.
- Keep findings reported from inside a container attached to that container instead of its host.
- Stop a scan from overwriting subnets and host overrides belonging to another scan's daemon.
- Refresh Last seen on VLANs each time a scan reports them again.
- Let an identified service replace its earlier placeholder entry rather than creating a duplicate.
- Match UniFi Next-Gen Gateways so they're identified correctly.
- Match SSH credentials on the port they're configured for.
- Withhold only the credentials an older daemon can't use, instead of skipping the whole set.
