This release sharpens how Scanopy identifies the devices on your network, and tidies up how plans, features, and navigation are organized.

## New Features

- Fingerprint devices using Recog, IEEE OUI and TCP/IP stack signatures for more accurate device types, with fewer bogus classifications from software-only matches.
- Show where a host's device type came from in the device facts card, so you can tell which signal identified it.
- Recover your open tabs automatically after a server restart or upgrade, so an update no longer wipes your workspace.
- Add a banner that tells you when the Scanopy server is unreachable, replacing the old update banner.
- Email the organization owner when a trial is extended.

## Improvements

- Reorganize plan cards into clearly labelled feature groups with icons, and rename features to match the app (Network Mapping, Network Discovery, Topology, Inventory).
- Rename the Assets sidebar section to Inventory and group Credentials under Discovery, making navigation match how you actually work.
- Deliver live updates over a single connection per tab, making real-time changes more reliable and lighter on the server.
- Warn before a page reload discards unsaved changes.
- Dim credential types that can't be selected, and let organizations create credentials before any hosts are discovered.
- Point self-hosted empty states at your own server, with clearer wording throughout.
- Require email verification before a license plan activates, and show clearer feedback on the verification and terms screens.
- Ship third-party license notices with the app.

## Bug Fixes

- Fix stray addresses appearing in discovery results.
- Ignore container bridge interfaces on the daemon host when calculating reachability, preventing misleading connectivity.
- Explain in the scan digest when a host had no matching credentials, instead of reporting an unclear failure.
- Stop showing upgrade and license key banners in the plan picker, where they were out of place.
