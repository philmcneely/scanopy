This release reworks how plans and trials work for cloud organizations, and adds better detection for Google Wifi and Nest mesh routers. It also renames several API paths. If you call the API with an API key, read Breaking Changes before you upgrade.

## Breaking Changes

- Rename four API paths to plural collection names: `/api/v1/discovery` is now `/api/v1/discoveries`, `/api/v1/topology` is now `/api/v1/topologies`, `/api/v1/auth/daemon` is now `/api/v1/daemon-api-keys`, and `/api/v1/auth/keys` is now `/api/v1/user-api-keys`. Update any scripts that call the old paths. Daemons need no update.
- Revoke invites with `DELETE /api/v1/invites/{id}` and `POST /api/v1/invites/bulk-delete`, and consolidate hosts with `POST /api/v1/hosts/{id}/consolidate/{other_id}`.

## Plan Changes

- New cloud organizations start on Free. To start a trial, pick a plan and add a card. The card form shows the date of your first charge.
- Free no longer caps hosts. It no longer includes the topology view, tagging, PNG export, or more than one daemon. Organizations with several daemons keep them but can't add another.
- Cloud plans that end now move to Free instead of becoming read-only.
- Trials that started before this release and have no card move to Free when they end, unless you add a card.

## New Features

- Start a trial automatically at signup, with a clearer card form that explains exactly when and what you'll be charged.
- Add Google Wifi and Nest router detection, so mesh access points are identified correctly in your topology.

## Improvements

- Group nested device trees above ungrouped rows for easier scanning of large lists.
- Give slow devices more time to answer application probes, improving detection accuracy on busy networks.

## Bug Fixes

- Fix false-positive UDP services by requiring a valid probe response before reporting a match.
- Fix the app getting stuck after deleting an organization or signing out from the terms screen.
- Use the correct AirPlay icon for AirPlay Receiver devices.
