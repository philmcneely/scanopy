This release reworks how plans and trials work for cloud organizations, and adds better detection for Google Wifi and Nest mesh routers.

## New Features

- Introduce the Free plan for cloud organizations, including a default scheduled scan so new workspaces start discovering right away.
- Start a trial automatically at signup, with a clearer card form that explains exactly when and what you'll be charged.
- Add Google Wifi and Nest router detection, so mesh access points are identified correctly in your topology.

## Improvements

- Show the current scan phase next to the progress bar, and surface the same progress on the Scans tab so you can tell what a running scan is actually doing.
- Distinguish host applications from service applications in the inspector, making it clearer where a detected app is running.
- Group nested device trees above ungrouped rows for easier scanning of large lists.
- Give slow devices more time to answer application probes, improving detection accuracy on busy networks.
- Widen the topology modal shown while discovery is still pending, and focus the organization name field during onboarding.

## Bug Fixes

- Fix false-positive UDP services by requiring a valid probe response before reporting a match.
- Fix the app getting stuck after deleting an organization or signing out from the terms screen.
- Use the correct AirPlay icon for AirPlay Receiver devices.
- Fix the demo organization so the TrueNAS host correctly appears on multiple networks.
